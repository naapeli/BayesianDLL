Samplers
========

BayesianDLL provides Hamiltonian Monte Carlo (No-U-Turn Sampler / NUTS), random-walk Metropolis,
multivariate slice sampling, and discrete finite Gibbs sampling, as well as Sequential Monte Carlo (SMC)
and exact ancestral predictive draws.
